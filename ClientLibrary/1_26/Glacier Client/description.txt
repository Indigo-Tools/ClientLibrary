Glacier Client by Pepe is another client Pepe made. He owns this one, just like Project Light. Glacier v1 through v3 came before Project Light. The name of Glacier was kind of destroyed by haters, so Pepe made Project Light. He still loved Glacier in his heart, so after Project Light v4, he continued Glacier. Now there are v4, v5, v6, and v7 coming, with Java and DLL client versions planned soon. Project Light was based on Glacier, and Glacier is based on Project Light. It has a clean UI, it is lightweight, and it has a mod menu with 37+ modules and more than 100 features, all optimized for all devices.
