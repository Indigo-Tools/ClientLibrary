# Glacier Client

A premium, free JSON UI texture pack for Minecraft Bedrock Edition (1.21+) that enhances visuals and performance with a fully customizable HUD and optimized utility modules. Runs smoothly on **Windows**, **Android**, and **iOS**.

## ✨ Features

* **Mod Menu** — a tabbed interface (Modules, Elements, Editor, Music Player) to toggle, configure, and freely drag, scale, and reposition every module on screen.
* **HUD Modules** — Armor HUD, Status HUD, Direction HUD, Target HUD, Main/Off-hand HUD, Bow Indicator, Speedometer, FPS counter, coordinates, day-event timer, walk distance, and more.
* **Item Counters** — live tracking for Totems, Splash Potions, Arrows, and per-slot counts, plus low-durability and shiny-potion alerts.
* **Navigation & Tracking** — chunk map, ore visualizer, custom timers, EXP calculator, player list, server display, and automatic death coordinates.
* **Custom Containers** — redesigned chest, brewing stand, furnace, anvil, enchanting, and smithing table screens with a tooltip display panel and brewing guide.
* **Visual Styling** — customizable crosshairs, hotbar themes, styled XP bars, brightness overlay, and an animated start screen with changelog.
