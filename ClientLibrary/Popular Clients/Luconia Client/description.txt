Luconia was first named "Curation Client" by Lumo (who used a different name at the time). Then, Lumo created a new Discord account and gave the ownership of the Curation Discord server to it. He rebranded it to Luconia, giving it a fresh start. Luconia Client was one of the most popular clients ever made. It was the first one to release a working mod menu for PCs and mobile devices. A lot of people were upset about it because the client community was at its best. Some of the problems include stolen code and the Discord moderator "Blue Boy". Additionally, Luconia v2 was very highly anticipated, but it never released because the original creator, Lumo, quit and switched to YouTube under the new name "Flxshed." The new owner, Nyami, never really managed to create version 2, but they did create a beta DLL for Luconia. They promised a better version, which of course never happened or is still in the works.
